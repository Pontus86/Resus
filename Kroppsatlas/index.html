Om atlasen

Utforska hela kroppen i 3D. Slå på/av hela system (skelett/muskler/nerver/kärl/ledband), filtrera på region eller sida, sök efter en specifik struktur eller klicka direkt i modellen för att markera och isolera den. Data: skelett/mjukdelar från Open3DModel (anatomytool.org, CC-BY-SA 4.0) kalibrerat mot samma hjärn-/ryggmärgsdata som Neuro-modulen använder — ej kliniskt verifierat, för utbildningsbruk. Muskler/nerver/kärl saknar för närvarande bål/rygg (endast armar/ben) eftersom källbiblioteket ännu inte publicerat den regionen.
