================================================================
 BLOOD GAS PHOTO EXTRACTION — 14 examples
================================================================
For each image: sample type, analyser/format, and every value
relevant to the app. Units follow what is printed on each report
(pCO2/pO2 in kPa throughout). "*" in the source = flagged out of
range; I have NOT carried the asterisks into the values below.

Swedish label reminders:
  vB / P(vB) = venous   |   aB / P(aB) = arterial
  Basöverskott / cBase(Ecf) / ABE = base excess (BE)
  Standardbikarbonat / cHCO3-(P,st) = standard bicarbonate (HCO3)
  Anjongap (exkl K+) = anion gap (excluding K+)
  Kreatinin = creatinine | Klorid = chloride | Natrium = sodium
  Kalium = potassium | Glukos = glucose | Laktat = lactate
  KOMM / Ogiltigt = comment / invalid (no numeric result)
